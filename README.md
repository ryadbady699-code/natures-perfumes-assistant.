## 🚀 المشروع الأساسي — مستشار عطور الطبيعة الذكي (Interactive Perfume Seller)
**وصف المشروع:** تطبيق ويب ذكي يعمل كبائع ومستشار عطري تفاعلي، صُمم لدعم اللغة العربية بالكامل، يقرأ وصف المستخدم ويقترح العطر الأنسب من مجموعة عطورنا الفريدة بناءً على الذكاء الاصطناعي وحساب نسب التشابه اللغوي.

### 🎯 نقاط القوة الفنية للمشروع:
1. **فهم التحية الطبيعية:** التعرف التلقائي على تحيات الزوار باللغة العربية والرد الفوري بأسلوب ترحيبي دافئ يعكس هوية علامتنا التجارية.
2. **معالجة النصوص (NLP):** تحويل كلمات المستخدم وأوصاف العطور إلى متجهات رياضية رقمية باستخدام خوارزمية **TF-IDF**.
3. **حساب المطابقة الذكية:** استخدام معادلة **Cosine Similarity** الرياضية لحساب تطابق ذوق العميل مع مكونات العطور واقتراح العطر الأنسب بنسبة مئوية دقيقة.
4. **حفظ تاريخ المحادثة:** واجهة دردشة تفاعلية ومرنة تحفظ سياق الحوار بالكامل لتمنح العميل تجربة تسوق متكاملة وممتعة.
